# Perhitungan-Alternating-Digit-Sum-Penjumlahan-Angka-Secara-Bergantian-Positif-Negatif-dari-Belakang-
Program ini menghitung jumlah digit dari suatu bilangan bulat n secara bergantian antara positif dan negatif, dimulai dari digit paling belakang. Tanda bergantian tiap digit: digit ke-1 positif, digit ke-2 negatif, digit ke-3 positif, dan seterusnya.
